# 杭州旅游攻略

这是一个用于练习“本地代码上传到 GitHub，并通过 GitHub Pages 发布到公网”的静态网页项目。

## 页面内容

- 三天两晚杭州路线
- 西湖、灵隐寺、河坊街、西溪湿地等景点建议
- 美食、住宿区域和出行提醒

## 本地预览

```bash
cd /Users/crann_lou/github-pages-demo
python3 -m http.server 5173
```

然后打开：

```text
http://localhost:5173
```

## 发布

修改后在 GitHub Desktop 中提交，然后点击 `Push origin`。GitHub Pages 会自动更新公网网页。
